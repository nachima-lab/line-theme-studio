# LINE着せかえ制作室

既存のLINE作品制作室（Sites版）とは独立した、GitHub Pages公開の静的Webアプリです。

## Phase 0〜2

- 公式画面から採取した参考配色50種類（9系統）を選択し、トーク画面のプレビューを切り替え
- ヘッダーには `colors.header`、選択タイルには `colors.tileSurface` を使用
- 背景画像の登録・取り外し
- IndexedDBへのスキンと背景画像の自動保存、再読み込み時の復元
- ZIPバックアップの書き出しと読み込み（画像を元の形式で格納し、Base64変換を回避）。旧JSONバックアップの読み込みも対応
- ヘッダー文字色は視認性を優先して白／黒を自動選択（公式の文字色データではありません）

## 確認手順（iPhone Safari）

1. スキンを変更し、背景画像を登録して「自動保存済み」が表示されることを確認する
2. Safariでページを再読み込みし、スキンと背景画像が残っていることを確認する
3. 「バックアップを書き出す」でZIPをファイルに保存する
4. スキンを別の色に変更し、バックアップを読み込んで元のスキンと背景画像が復元されることを確認する
5. B/W 02などの暗いヘッダーで文字が白く読めることを確認する

バックアップ読み込みは現在の作品を置き換えます。IndexedDBはSafariのサイトデータ削除やストレージ管理で消える可能性があるため、バックアップを別の場所に保存してください。ZIPは画像を再圧縮しないため、元画像自体の容量は減りません。ZIPには project.json と images/ 内の元画像が入ります。旧JSONバックアップは引き続き読み込めます。

## 構成

- `index.html`：画面
- `css/style.css`：見た目
- `js/app.js`：操作・画面制御
- `js/skins.js`：スキンの読み込み
- `js/preview.js`：トークプレビュー
- `js/store.js`：IndexedDB・作品形式・バックアップ
- `data/color-skins.json`：配色データ

サーバー、ログイン、フレームワーク、ビルドツールは不要です。Phase 3の62ファイル生成やPhase 4の別画面プレビューは未実装です。
